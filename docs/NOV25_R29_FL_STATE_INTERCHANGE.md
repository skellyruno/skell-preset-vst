# FL saved-state interchange (R29)

Portable offline C++17 state codec and inspector preserve original payload bytes. Validated against 126 recovered saved occurrences, 69 distinct payloads, in private research. Strict lengths and versions, dynamics raw values checked, optional flags and source sidechain index preserved. Unsupported formats rejected. EQ2 v8, multiband v0, stereo and soft clipper inspection-only; no guessed parameter mappings. Limiter v7 and compressor v1–3 allow editing known raw controls in a copy. CLI never intentionally overwrites existing files. Not a full FLP/FST reader/writer.

The raw-state codec is separate from the existing rack/APVTS schema. Full limiter needs 18 controls plus an exact-ceiling flag; cannot truncate to the 16 generic slot parameters. The compressor's saved lookahead report flag is not its physical latency. No production effects, IDs, factory states, UI or .skellpreset schema changed. External routing/enable state cannot be inferred from payloads. New meter history utility uses supplied level axis and 87 columns/s, bounded storage and invalid-input guards; UI thread only, peak ratio not gain reduction. Actual editor integration and JUCE/FL validation pending.

Local strict compilation and 91,741 codec checks passed, including every normalized raw integer of supported dynamics controls. History regression passed. Real edits on 36 distinct dynamics states changed only the requested four bytes, and existing output rejection passed. 144 real-vocal render comparisons (four sample rates) of the newly supplied source vs previous source were identical, using an offline shim; previous block-size dependency remains. Private original DSP, actual states, audio and research artifacts not committed.
