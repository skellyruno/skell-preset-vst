# Shared native matching dependency

Pinned SkellCore 92b03b753c59583b6b6063228c2d630ef94daf59 (draft PR #47). The only migrated header is ClubGate.h, hash-checked and staged into an isolated generated include directory so older DSP and UI dependencies cannot be accidentally shadowed. Both existing gate classes are aliases; the processor uses the same clubGateGain function as the native CLI. Existing factory settings, automation IDs, state and default-OFF experimental finish are unchanged. The matching CLI models the gate with fixed parameters and optional output trim; the full processor also has host-owned wet smoothing, input gain, and other stages. Full wrapper parity is still required; do not claim that a standalone gate output is the whole plugin output.

Build with the existing portable tests or normal JUCE CMake target. For an offline checkout, set FETCHCONTENT_SOURCE_DIR_SKELLNATIVEMATCHHEADERS to the pinned SkellCore source root; header SHA verification remains mandatory. Local JUCE/GitHub DNS unavailable.
