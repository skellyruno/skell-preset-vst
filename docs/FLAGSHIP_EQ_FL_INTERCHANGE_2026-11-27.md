# Flagship EQ and FL interchange — 2026-11-27

- Studio EQ remains an independent native design. Legacy EQ and eight-band Tone remain unchanged.
- Bell nodes can opt into stereo-linked dynamic cuts (alt-click, initial depth 6 dB; host automation 0–12 dB). Threshold -24 dBFS, attack 12 ms, release 110 ms. The graph shows static coefficients and a ring for configured dynamics, not an invented gain-reduction trace. Dynamic depth is appended to host parameters and optional in preset v2; old states default off.
- FL mixer FST parser inventories actual named 0xC9/0xD5 records. Do not infer effect identity from payload length alone. The standalone converter translates only named EQ2 v7/v8 payloads, explicitly approximate; each export is a NEW one-EQ rack, not a whole mixer recreation. Import via existing native .skellpreset browser. Run `python tools/import_fl_fst.py FILE.fst` then `python tools/import_fl_fst.py FILE.fst --eq-record N --allow-approximate --output NEW.skellpreset`.
- Main EQ gain maps to the standalone rack output; HQ/linear phase and orders outside single stage are reported. Active unsupported band-pass/notch rejects conversion. Source file is never modified. Other FL records inventory only; do not label extraction as native effect import. FabFilter/Waves: not supported yet, require validated preset fixtures and physical parameter maps.
