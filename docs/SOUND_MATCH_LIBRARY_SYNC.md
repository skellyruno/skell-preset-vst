## Native automatic artist bank (R53, no end-user installer)

The owner requested no separate preset download/install. The Sound Match producer remains canonical; the plugin now accepts a **private build-time bank** and seeds its existing artist library on the ordinary editor/browser worker. No network calls, Python, package import dialog, or file writes in DSP/host-state recall. Artist, Main/Adlib, title and pairing are default metadata; explicit user sidecar values take priority. Clearing a custom value restores the managed default. Existing stable trial filenames and local edits are protected. Newer bank generations update only exact managed revisions; older binaries cannot roll them back. Backups remain immutable. A public/non-bundled build reads previously installed metadata, but cannot deliver private presets on a fresh machine.

Build/release agent (not the end user): generate the JSON with `python tools/prepare_artist_bank.py <private-catalog-directory> <private-output>/skell_artist_bank.json --generation 53`. Configure with `-DSKELL_ARTIST_BANK_FILE=<private-output>/skell_artist_bank.json -DSKELL_REQUIRE_ARTIST_BANK=ON`. Increment the generation for the next bank release. Do not commit the JSON, binary-data outputs, private packages or private build artifacts to a public repository or a public Actions workflow. A private VST3 already contains the bank; the user only replaces/updates the plugin normally. This is automatic delivery on plugin build updates, not a live cloud updater.

Local JUCE 8.0.12 core/cryptography build verified all 35 R53 packages (20 main, 15 adlib), byte-identical repeated seeding, managed revision upgrades, backup, downgrade guard, local edit and unmanaged collision protection, metadata persistence, and malformed bank rejection. These are native package tests, not FL Studio/VST3 host certification. Run NativeArtistBank and PrivateArtistBank (when the private bank is supplied) alongside NativePresetPackage. The screenshot-only bank fixture is opt-in via SKELL_ARTIST_BANK_QA=1 and a temporary application data root. Keep the PR draft. Windows delivery requires a private build channel; public CI exercises generic code only.

The private regression now links the generated binary-data target and invokes `syncEmbedded` with no external JSON path. Native Save and Import share the bank's cross-process mutation lock. Three simultaneous native processes on a clean isolated library produced exactly 35 packages and no conflicts; the R48 migration produced 23 new, 3 upgraded (with three exact backups) and 9 current, then 35 current on repeat. Renderer opt-in full audit adds artist directory, all, main and adlib bank pages. The existing cached-source renderer build is not an exact-head Windows verification.


## Artist artwork and cinematic browser rows

Artist default artwork is prepared once for the private bank. Use the exact artist ID in tools/artist_artwork_sources.json (verified profile URL + direct image URL). Priority: owner-provided hashed cover, curated official streaming avatar, official social avatar or curated release art, existing local preset covers, native fallback motif. The build producer caches normalized PNGs and embeds one asset per artist; no runtime HTTP, no audio-thread or paint-time decoding. User per-preset artwork overrides inherited artist art. The worker prepares sharp portraits and soft strip textures; list mode is the new default, with previous view preference retained and existing card/favorite hit targets unchanged. Thumbnails show the human-readable preset title. Artwork bytes and the private bank remain outside public Git. Use `--offline` for cache-only builds and `--require-artwork` for a private release that must include verified images. This requires Pillow on the build agent only. skellyruno's Spotify ID and exact image URL were located through the named artist profile link; direct image download was unavailable in the restricted environment. Do not claim the image is embedded until byte retrieval and native rendering are verified. For other artists, add an identity-checked source and ensure rights for redistribution before bundling into a public release. No DSP or factory/automation changes.

Artwork tests: `python tests/test_artist_artwork.py` uses only synthetic fixtures. Native `testViewSwitchForTest()` additionally checks image decoding, payload hash rejection, repeat-cache reuse, text contrast, and right-portrait bounds at minimum/maximum width. These fixtures are never installed into the owner's artist library. A private build must run `--require-artwork` before its bank-enabled configure; public CI intentionally has no private artwork payload.

The draft PR runs a narrowly scoped build-side artwork job using only the publicly linked, owner-requested skellyruno profile image, no private presets. The first exact Linux compile found a shadowing error in the added test fixture; corrected the identifier (`artRow`) rather than weakening the test. The artwork job verifies the source/cache tests and exports only the normalized public artwork with source provenance for private build preparation.
