# Sound Match library publishing contract (R48)

Sound Match is the canonical producer of versioned private recipes. Use the existing v2 native .skellpreset ZIP format (preset.json only), never an audio render or learned offline FIR disguised as a package. The local producer's preset_sync.py stages immutable SHA-256 revisions and publishes explicitly into the existing user application-data Skell Audio/Skell-Preset/Presets folder, with stable filenames and a separate trial channel. Close plugin instances before using an external writer. The browser rescans on open, reads ArtistTags.txt and LibraryOrganization.txt; title:user:<filename> is an optional display title only. Artist and type tags and adjacent PNG/JPG covers remain editable locally. Existing projects retain embedded APVTS state: no forced reload, network access, parameter or factory ID changes. History and installed manifest are outside the rack and outside audio processing. Do not overwrite locally edited/unmanaged files. Native approval is separate from offline listening approval. The default trial pack is private; no owner audio, coefficients or packages in Git.

The former 200-entry cap is expanded to 1000 across library, artist/genre legacy metadata, and favorites (1064 including factory allowances). Metadata file limits are increased to 1 MiB. Update the existing bounded library fixture to exercise 1020 files. UI title fallback remains filename for legacy entries. Build and Quick4 UI checks required before promotion; external writer tested separately. See skellyruno/skell-sound-match for the producer. No current shipping VST3 claim.
