# R75 Sound Match backends (opt-in research)

Vendored byte-identical shared SkellCore headers from commit 0f0c7e70277f4308dfdedbc6e7b1031c8d63962c and standalone regression in this branch. CausalMatchCompressor has zero added algorithmic sample delay, uses completed input-only detector frames and ramps forward. Do not infer that the offline matching models have zero plugin latency. No active rack routing, factory preset, APVTS ID, state migration or UI change. The candidate is available as C++ source for integration; not yet a selectable production compressor.

The existing opt-in shared Skellay target already pins 8a0904b99dba671195f139907e09ac86a09ad5f4. New optional portable test combines its exact Delay2Engine with the shared compressor. This does not copy or replace the existing delay or native Skellay engine. Cache source hashes for Delay.cpp and Delay.h match the pinned Git blobs. Five rates (32/44.1/48/96/192 kHz), four block sizes (37/64/128/512), fixed synthetic beat impulse at 144 BPM, bypassed and enabled compressor cascade. Exact block parity; stereo tail comparison allows the native 2^-24 flush threshold. Initial strict stereo equality failed at tail floor and was replaced with a bounded 1.3e-7 tolerance; no engine change.

GCC O3 strict and ASan/UBSan passed 135 compressor configurations; the synthetic cascade passed GCC strict. R74 original isolated Delay2 recording error 0.000003948 at 44.1k only, not full-chain parity. R75 causal isolated compressor .739411 versus prior offline .604212. Private full-chain Free Main 1.796787 -> 1.795347, Free Full 1.854482 -> 1.791092, both nominal and stress peaks safe at both tested rates. Full chains still offline and retrospective; no listening or independent takes; exact current JUCE plugin and Windows host unverified. No private audio, raw state or fitted coefficients in Git.
